# Use of the Alamo DB name

The Alamo DB code is open source under Apache-2.0: you may use it, modify it
and redistribute it as the license allows. **The "Alamo DB" name and the logo
are not**: the code license does not grant them (Apache-2.0, section 6). This
page explains what you can do with the name without asking.

The purpose is a single one: whoever downloads something called "Alamo DB"
must receive Alamo DB, not a version modified by someone else. It is a
database client: the people who use it entrust it with their production
credentials.

## Without asking

- **Talking about it**: articles, reviews, tutorials, videos, comparisons with
  other tools, using the name to refer to the project.
- **Saying your product is compatible** with or integrates with Alamo DB
  ("plugin for Alamo DB", "works with Alamo DB"), as long as it does not look
  like an official product.
- **Redistributing the official builds unmodified**, with their name and logo.
- **Packaging the source** for a distribution or a package manager (Homebrew,
  Flatpak, a Linux distro) with only the changes the package requires (paths,
  dependencies, build), without changing features or appearance.
- **Forking to contribute**: a fork on GitHub whose purpose is to propose
  changes to the project may keep the name.

## A different name is required

If you **publish a modified version** (a fork with different features, a build
with your own changes, a product based on the code), you must:

- give it a **different name**, which neither contains "Alamo" nor can be
  confused with it;
- use a **different icon and logo**;
- not present it as official or endorsed by the project.

You may say where it comes from: "based on Alamo DB" is allowed.

## Not allowed

- Using the name or the logo for a product, service or domain that could look
  official.
- Selling modified builds under the Alamo DB name.

## Questions

If you are not sure whether a use is allowed, open an issue and ask.
